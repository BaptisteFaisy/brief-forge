# Format du compte rendu de travail

Un compte rendu d'agent comprend les sections suivantes en Markdown :

- **Fait** : résumé précis des modifications apportées.
- **Non fait** : ce qui a été exclu ou reporté, avec justification.
- **Critères couverts** : numéros des critères d'acceptation validés (ex: 1, 2, 4).
- **Hypothèses prises** : choix techniques effectués en l'absence de spécification.
- **Tests lancés et résultat** : commandes exécutées et statut (ex: unit tests passés).
- **Suites proposées** : recommandations ou prochaines étapes pour l'équipe.
